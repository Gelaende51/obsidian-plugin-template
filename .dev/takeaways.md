# Takeaways

Challenges, oddities and undocumented behaviour found while building this plugin.
Kept for reference, and as raw material for bug reports or API requests.

> **Where does a finding go?** Ask what would make it false.
>
> - A future **Obsidian release** could → it is not about this plugin. It belongs in the
>   shared lore repository, stamped with the version you verified it against.
> - Only a change to **this plugin** could → here.
> - **Nothing could** — it is about how to work, not about any system → it is a method
>   rule, not a finding.
>
> This file fills up with the middle category. It stays small if the other two are
> filed where they belong; the previous project's reached 37 entries, most of which
> were not about that project at all.

Write each entry as: what is true, how it shows up, what to do instead. Keep the
symptom — that is what a reader is searching for.
